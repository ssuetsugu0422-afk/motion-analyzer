Motion Analyzer

動画を選んでください

下の「動画を選ぶ」ボタン、またはここにドラッグ＆ドロップ

1. 動画を読み込む

物体の動きを、カメラを固定して真横から撮った動画を使います。

PCでは動画をドラッグ＆ドロップでも読み込めます。

2. 動画の設定と長さの基準

加速度を求めるときは、間隔が 0.03〜0.1 秒くらいになるようにすると安定します。

動画の中で長さが分かっているものの両端を1点ずつタップします（3回目のタップでやり直し）。

m
→ 1点目をタップしてください

3. 座標軸（原点と正の向き）

位置 x を測る向きを決めます。鉛直投射・自由落下はどちらも「上向き」（または下向き）にすれば、同じ設定で分析できます。

正の向き
→ 原点（x = 0）にする場所をタップしてください

4. 物体の位置を記録

物体の中心をタップ（PCはクリック）すると記録し、自動で次のコマへ進みます。指を当てたまま動かすと拡大鏡で狙いを調整できます。

スマホを横向きにすると、動画が大きく表示されて狙いやすくなります。

キーボード：← → でコマ移動（Shift で10コマ）、Backspace で1点取り消し。

記録を始める前に、スライダーで動き出す少し前のコマに合わせてください。同じコマをもう一度タップすると位置を上書きします。

動き出す前や止まった後のコマを記録してしまったときは、x-t グラフでその点をタップすると計算から外れます（灰色になり、t = 0 は残った最初の点に合わせ直します）。スライダーでそのコマを表示して「このコマの点を消す」でも削除できます。

解析の設定

速度・加速度の点は、前後の点を2次式で近似して求めます。点数を増やすほどばらつきが減りますが、急な変化はならされます。グラフの点をタップすると、その点を外せます（もう一度で戻す）。x-t で外した点は速度・加速度の計算からも外れ、v-t・a-t で外した点はそのグラフの近似だけから外れます。

結果

3点以上記録するとグラフと結果が表示されます。

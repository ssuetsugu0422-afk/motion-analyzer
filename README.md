# Motion Analyzer

物体の運動を撮影した動画から位置を記録し、x-t・v-t・a-t グラフを作るブラウザアプリです。インストールは不要で、PC・iPad・スマートフォンで使えます。

## 使い方

1. **動画**：カメラを固定して真横から撮った動画を選びます。フレームレートは自動で読み取ります（読み取れないときは選ぶ。スマホの標準は30fps）。
2. **長さの基準**：長さが分かっているものの両端をタップし、その長さを入力します。
3. **座標軸**：原点をタップし、正の向き（上・下・右・左、または2点で任意の向き）を選びます。
4. **記録**：物体の中心をタップすると記録して次のコマへ進みます。

## 対応している運動

- 等加速度直線運動（自由落下・鉛直投射・斜面など）：x-t の2次近似から加速度 a = 2A を求めます。
- 単振動：x-t を正弦曲線で近似し、周期・振幅・ω² を求めます。a-x グラフも表示します。

動き出す前や止まった後のコマは、x-t グラフで点をタップすると計算から外せます。動画や記録は端末の中だけで処理され、外部には送信されません。
